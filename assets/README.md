# assets

The canvas expects one image here:

| File | Used by |
|---|---|
| `hm-sultan-haitham.png` | The "His Majesty" panel (`.hm-photo`) on the left of the hub |

The panel crops it to a 308px-wide portrait column (`object-fit: cover`,
anchored near the top of the frame), so a head-and-shoulders shot on a plain
background works best.
